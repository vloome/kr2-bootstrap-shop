## О проекте

Многостраничный учебный сайт интернет-магазина ShopProject. Страницы сделаны на HTML, оформлены Bootstrap 5.3.3 и собственными стилями. JavaScript используется для показа данных выбранного товара и предварительного выбора товара в форме. Серверной отправки заявки в проекте нет.

## Страницы и файлы

```text
kr2-bootstrap-shop/
├── index.html          # Главная: акция, баннер, преимущества и популярные товары
├── catalog.html        # Каталог: фильтры интерфейса и сетка из трёх товаров
├── product.html        # Карточка товара и характеристики; товар выбирается через ?id=
├── order.html          # Форма заявки; товар выбирается через ?product=
├── contacts.html       # Контакты и FAQ на Bootstrap Accordion
├── css/
│   └── custom.css      # Собственные стили, включая оформление баннера
└── images/
    ├── background.jpg
    ├── product-1.jpg
    ├── product-2.jpg
    └── product-3.jpg
```

Bootstrap JavaScript размещён непосредственно на HTML-страницах через CDN; отдельного файла JavaScript в репозитории нет. Небольшие скрипты страницы товара и формы заявки находятся в соответствующих HTML-файлах.

## Подключение Bootstrap и собственных стилей

На каждой странице Bootstrap 5.3.3 подключается через jsDelivr CDN: CSS-файл находится в `<head>`, а `bootstrap.bundle.min.js` подключён перед закрывающим `</body>`. Bundle включает Popper, необходимый интерактивным компонентам. После Bootstrap CSS загружается `css/custom.css`, чтобы собственные правила могли переопределять оформление фреймворка.

## Компоненты Bootstrap в проекте

- `navbar` и `collapse` — навигация и мобильное меню;
- Grid System: `container`, `row`, `col-*`, адаптивные колонки и `g-*`;
- `card`, `btn`, `badge`, `alert`;
- `modal` — справочное окно на странице заявки;
- `breadcrumb` и `table`;
- элементы формы: `form-control`, `form-select`, `input-group`, `form-check`;
- `accordion` — блок часто задаваемых вопросов на странице контактов.

## Как работает интерфейс

На странице товара скрипт читает параметр `id` из адреса, например `product.html?id=2`, и показывает соответствующие название, изображение, описание, цену, метку и характеристики. Если параметр отсутствует или не соответствует товару, показываются данные первого товара.

Ссылки «Заказать» передают идентификатор в адрес страницы заявки, например `order.html?product=2`. Скрипт страницы заявки выбирает этот товар в списке формы. Bootstrap управляет мобильным меню, FAQ-аккордеоном, закрытием уведомления и открытием/закрытием модального окна.

Форма проверяет обязательные поля средствами браузера. Она не сохраняет и не передаёт заявку: серверная часть не реализована. Фильтры в каталоге показаны как элементы интерфейса и пока не фильтруют товары.
