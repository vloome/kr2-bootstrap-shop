## Описание проекта
Многостраничный учебный интернет-магазин, разработанный с нуля с использованием CSS-фреймворка Bootstrap 5. Проект включает адаптивную верстку, кастомную стилизацию, динамическую подгрузку карточек товаров через URL-параметры, интерактивную форму заявки и дополнительные компоненты интерфейса.

## Используемый фреймворк
* **Bootstrap** (версия 5.3.3)

## Способ подключения
Bootstrap подключён через официальный **CDN** (в заголовке `<head>` для стилей и перед закрывающим тегом `</body>` для JS Bundle). Кастомный файл стилей `css/custom.css` подключен строго после стилей Bootstrap для корректного каскадирования.

## Реализованные Bootstrap-компоненты
* `navbar` (адаптивная навигация с бургер-меню)
* `container`, `row`, `col-*`, отступы через сетку (Grid System)
* `card` (карточки товаров и блоков)
* `btn` (кнопки с различными модификаторами)
* `badge` (значки «Хит», «Новинка», «Скидка»)
* `alert` (информационные блоки уведомлений)
* `modal` (модальные окна)
* `table` (таблицы характеристик товаров)
* `form-control`, `form-select`, `input-group`, `form-check` (поля ввода, селекты, чекбоксы)
* `accordion` (аккордеон с часто задаваемыми вопросами в разделе контактов)
* `breadcrumb` (хлебные крошки для навигации)

## Самостоятельные доработки сверх базового уровня
1. Реализована клиентская шаблонизация и связность страниц через URL Query Parameters (`?id=` и `?product=`), что позволяет динамически отображать контент конкретного товара без создания дублирующих HTML-файлов.
2. Добавлен компонент `accordion` (FAQ) на страницу контактов.
3. Интегрированы информационные блоки `alert` для подтверждения пользовательских действий.
4. Настроена плавная якорная кнопка возврата наверх («Наверх») во всех частях интерфейса.
