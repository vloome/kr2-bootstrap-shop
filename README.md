# Учебный проект — Контрольная работа № 2

## Описание
Проект выполнен в рамках дисциплины «Фронтенд и бэкенд разработка». Тема: разработка многостраничного сайта интернет-магазина (КР №2).

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница карточки товара;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений (`background.jpg`, `product-1.jpg`, `product-2.jpg`, `product-3.jpg`).
